# 几何决斗：霓虹远征

离线运行的 HTML5 Canvas 几何 Roguelite。选择核心，组合武器、元素、协同升级与遗物，穿越三章远征，或挑战 Boss Rush 与无限模式。

## 启动

ES 模块需要通过 HTTP 服务器加载，不能直接双击 `index.html`。

推荐直接双击 `start.bat`。脚本会在 `127.0.0.1:8081` 启动本地服务器并打开游戏。

也可以在本目录执行：

```bash
python -m http.server 8081 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8081/index.html`。

## 操作

| 按键 / 操作 | 功能 |
| --- | --- |
| `WASD` | 移动 |
| 鼠标移动 / 左键 | 瞄准 / 手动连射；不会中断自动锁定 |
| 右键 | 冲刺，短暂无敌 |
| `Q` / `E` / `F` | 鱼钩 / 蛛网 / 护盾 |
| `K` | 自动锁定最近敌人 |
| `Shift` | 切换双武器 |
| 按住 `Tab` | 查看当前 Build |
| `Esc` | 暂停，或从菜单返回标题 |

## 游戏内容

- 5 个核心：初始可用方块、三角、六边形；圆环与八角在机库消耗核心解锁。
- 66 把武器：11 种弹道类型均具备白、绿、蓝、紫、橙、红六阶；红色武器拥有高暴击、破盾/反射增伤、吸血与专属战斗反馈。
- 火、冰、雷三种元素：火冰蒸发、火雷超载、冰雷冻结。
- 双穿透、双追踪、同品质武器可获得专属协同升级。
- 6 枚遗物、连击倍率、五种新增敌人、三章各 9 波与三位 Boss。
- Boss Rush：选择核心后，从橙色武器中自选两把不同武器，再连续挑战三位 Boss；无休息区。
- 无限模式：通关第三章后解锁；每 5 波 Boss，最高波次保存在本地。
- 战斗世界为 1920×1080，视口会跟随玩家移动；HUD 右上角小地图显示玩家、敌人、Boss 与当前视野。
- 标题页可开启“赖皮模式”：受到致命伤时生命会保留为 1，不触发失败结算；战斗 HUD 会显示红色提示。
- 图鉴通过“武器 / 敌人”标签切换，完整展示武器属性、弹道类型及敌人的几何预览和作战参数。
- 休息区将已装备的两把武器置顶单独显示；背包只展示未装备武器，换装会自动回收旧武器。
- 战后升级采用章节解锁与加权抽选；可消耗碎片重抽，并可能出现碎片、全修复、遗物试炼、武器进阶、元素淬炼或升级拆解等特殊奖励。
- 每章商店有主题商品，前三件固定保留至售出；精英会掉落紫/红武器，Boss 固定掉落红武。
- 主菜单提供 8 项成就与进度，结算页展示战绩、构型摘要并可复制 Build 代码。

## 存档与设置

进度使用浏览器 `localStorage` 保存。旧版 v1-v3 存档会自动迁移至 v4，保留核心、机库、图鉴、基础统计与音频设置。

标题页的“设置”可拖拽调整总音量、音效与音乐音量，并提供：

- JSON 存档导出与导入
- 红色武器发光、允许跳过升级、战斗提示开关
- 二次确认的完整存档重置
- 独立统计重置

音效与背景音乐由 Web Audio API 合成，不依赖外部资源；浏览器首次交互后才会播放声音。

## 项目结构

```text
几何决斗-战术版/
├── index.html              # Canvas 页面与存档文本框
├── start.bat               # 本地服务器启动脚本（8081）
├── css/roguelite.css       # 自适应画布与设置弹窗样式
├── js/content.js           # 核心、武器、敌人、章节、遗物、机库数据
├── js/state.js             # 局内状态、本地存档、迁移与奖励逻辑
├── js/audio.js             # 离线合成音效与背景循环
├── js/main.js              # 战斗循环、渲染、输入与 Canvas 界面
└── tools/roguelite_smoke_test.js
```

## 验证

启动服务器后，在本目录运行：

```bash
node tools/roguelite_smoke_test.js
```

测试会检查 v4 存档迁移、66 把武器品质完整性、红武掉落、升级重抽、特殊奖励、主题商店、成就、赖皮模式、持续自动攻击、扩展世界与镜头、小地图、音量拖拽、图鉴切换、暂停升级明细、休息区换装、无限模式与 Boss Rush 选装，并生成桌面与移动端截图。
